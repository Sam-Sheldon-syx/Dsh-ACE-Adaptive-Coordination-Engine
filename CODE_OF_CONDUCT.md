# Code of Conduct

This project is a small research collaboration. Participants are expected to:

- be respectful and specific when discussing technical disagreements;
- critique ideas and code, not people;
- avoid harassment, discrimination and personal attacks;
- respect privacy: do not publish another person's credentials, session data,
  local paths or private messages;
- disclose conflicts of interest when relevant.

Maintainers may remove comments, issues or contributions that violate these
expectations. Serious concerns can be raised through the repository's private
security/contact channel.
